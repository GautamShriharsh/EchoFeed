# EchoFeed AI

EchoFeed AI is a full-stack anonymous messaging platform where users can receive anonymous feedback and messages through personalized public links. The platform also features AI-powered message suggestions to encourage meaningful interactions.

## Features

- Anonymous messaging through public user links
- Secure authentication and email verification
- AI-generated message suggestions using Groq + AI SDK
- Protected and public route architecture
- Responsive modern UI with Tailwind CSS and shadcn/ui
- Form validation using React Hook Form and Zod
- Dynamic routing with Next.js App Router
- MongoDB database integration
- Toast notifications and smooth UX interactions

## Tech Stack

### Frontend
- Next.js 15
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- Next.js API Routes
- MongoDB + Mongoose
- NextAuth
- Zod

### AI Integration
- Groq API
- AI SDK
